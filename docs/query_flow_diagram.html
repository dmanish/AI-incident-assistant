• JWT token included in Authorization header

• Query sent to backend API

🚪 STEP 2: API Gateway

• FastAPI receives POST /agent/chat or /agent/chat/v2

• JWT validation

• Extract user role from token

• RBAC checks for tool and document access

📄 main.py:381-520 (/agent/chat) 📄 main.py:524-780 (/agent/chat/v2) 🔐 main.py:98-102 (JWT Validation)

🤔 STEP 3: Agent Selection

• /agent/chat → Heuristic Agent (semantic routing)

• /agent/chat/v2 → Function Calling Agent (LLM-powered)

• Multi-LLM failover: OpenAI → Anthropic → Google → Heuristic

📄 agent.py:1-100 (Heuristic) 📄 function_calling_agent.py:15-350
↓

🧭 STEP 4: Semantic Routing (3-Tier System)

TIER 1: Override Rules (Confidence: 1.0, ~2ms)

• CVE ID patterns, IP addresses, URLs

• Explicit keywords ("show logs", "password policy")

TIER 2: Vector Search (Confidence: 0.60-1.0, 30-40ms)

• ChromaDB similarity search with 48 training examples

• L2 distance → similarity conversion

TIER 3: Keyword Fallback (Confidence: 0.3-0.5, <2ms)

• Simple keyword matching as safety net

📄 semantic_router.py:26-260 (SemanticRouter class) 📄 rule_matcher.py:10-100 (RuleMatcher) ⚙️ routing_rules.yaml 📊 Training Examples (40+ examples)
↓

🧠 STEP 6: LLM Synthesis

• Combine tool results into context

• Multi-provider failover (OpenAI → Anthropic → Google)

⏱️ Time: 1-5 seconds (60-80% of total time)

🎓 STEP 10: Continuous Learning (NEW!)

Feedback Collection:

• User can flag routing as correct/incorrect/partial

• System records feedback with expected routing

• Feedback stored in routing_metrics.db

Pattern Analysis:

• Weekly analysis of feedback patterns

• Identify queries with consistent incorrect routing

• Auto-generate training examples (5+ occurrences)

Model Improvement:

• Admin reviews generated examples

• Approved examples added to seed_examples.json

• Re-ingest to rebuild routing vector database

• Continuous accuracy improvement over time
