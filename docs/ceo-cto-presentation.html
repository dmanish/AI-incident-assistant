✨ Implemented Features - Part 1

1. Three-Tier Semantic Routing 🆕

File: app/agent/semantic_router.py

Tier 1: Override Rules (Config-based)

  • YAML configuration with 7 rule categories
  • Priority-based matching (regex + keywords)
  • Examples: CVE queries → web only, Log queries → logs only

Tier 2: Vector Semantic Search

  • ChromaDB with 40+ training examples
  • Cosine similarity matching
  • Confidence thresholds: High (>0.7), Medium (0.5-0.7), Low (<0.5)
  • Replaces keyword matching with semantic understanding

Tier 3: LLM Fallback

  • Simple heuristics when confidence is low
  • Default to RAG if uncertain
  • All decisions logged for learning
Result: More accurate routing than keyword matching, adapts to natural language variations

2. Function Calling Agent 🆕

File: app/agent/function_calling_agent.py

  • True Agentic Behavior: LLM decides which tools to call, when, and in what order
  • Iterative Reasoning: Up to 5 iterations - agent can call tools, see results, call more tools
  • Multi-Provider: OpenAI (primary) → Anthropic → Google (automatic failover)
  • Parallel Execution: Multiple tools can run concurrently
  • Conversation Memory: 60-minute TTL for multi-turn conversations
Example Agent Flow:
  1. User: "Check IP 1.2.3.4 and see if user jdoe logged in from there"
  2. Iteration 1: Agent calls search_threat_intelligence(ip="1.2.3.4")
  3. Iteration 2: Agent calls search_authentication_logs(username="jdoe")
  4. Iteration 3: Agent synthesizes: "IP is malicious (AbuseIPDB score 95). Jdoe did log in from this IP on 2025-11-05. Recommend immediate password reset."

🎯 Improving RAG Accuracy - Near-term

1. Advanced Chunking Strategies

Current: Simple sliding window (800 tokens, 120 overlap)

Upgrade to:

  • Semantic Chunking: LangChain SemanticChunker - split by meaning, not just tokens
  • Hierarchical: Parent-child relationships (document → section → paragraph)
  • Adaptive Overlap: Dynamic overlap based on content type
  • Context Preservation: Include document metadata in each chunk

2. Better Embeddings

Current: all-MiniLM-L6-v2 (384-dim) or OpenAI text-embedding-3-small (1536-dim)

Upgrades:

  • text-embedding-3-large: 3072 dims, higher accuracy (+5-10%)
  • Domain-specific: Fine-tune on security corpus (CVEs, playbooks, etc.)
  • Multi-vector: ColBERT - multiple embeddings per chunk
  • Matryoshka: Adaptive dimensionality (512/1024/2048)

3. Query Enhancement

Current: Direct user query to vector search

Add:

  • Query Rewriting: LLM reformulates query for better retrieval
  • HyDE (Hypothetical Document Embeddings): Generate hypothetical answer, embed that
  • Multi-query: Generate 3-5 variations, retrieve for each, merge results
  • Query Expansion: Add synonyms and related terms

4. Re-ranking

Current: BM25 keyword re-ranking

Add:

  • Cross-encoder: BERT-based model re-scores top-20 (ms-marco, bge-reranker)
  • LLM Re-ranking: Ask LLM "Is this chunk relevant?" for top-10
  • Diversity: MMR (Maximal Marginal Relevance) to avoid redundancy
  • Metadata Boosting: Recent docs, specific doc types get higher scores

🏋️ How to Train a Custom LLM

Approach 1: Fine-tuning (Recommended)

Process

  1. Select Base Model: Llama 3.1 (8B/70B), Mistral (7B/22B), Gemma (7B)
  2. Prepare Dataset: 10K-100K question-answer pairs
    • Historical incident tickets (anonymized)
    • Security playbooks → Q&A format
    • Public datasets: CVE descriptions, attack scenarios
    • Synthetic data: GPT-4 generates training examples
  3. Fine-tune: LoRA/QLoRA for efficiency
    • Freeze base model weights
    • Train small adapter layers (1-5% of params)
    • Much faster & cheaper than full fine-tuning
  4. Evaluate: Test on held-out security scenarios
  5. Deploy: vLLM, TGI (Text Generation Inference), or Ollama for serving

Example Training Data

{
  "instruction": "What should I do if I receive a phishing email?",
  "input": "",
  "output": "1. Do NOT click links or download attachments
2. Report to security@company using 'Report Phishing' button
3. Delete the email
4. If credentials were entered, reset password immediately and enable MFA
5. Escalate to SOC if >10 users affected"
}

Infrastructure Requirements

Training

  • GPUs: 4-8x A100 (80GB) or H100
  • Time: 2-7 days for fine-tuning
  • Frameworks: Hugging Face, Axolotl, LLaMA Factory
  • Cost: $5K-$20K on cloud (AWS, Lambda Labs)

Inference

  • GPUs: 1-2x A100 or L4 (lower cost)
  • Optimization: Quantization (int8, int4 with bitsandbytes)
  • Serving: vLLM (3-10x faster), TensorRT-LLM
  • Cost: $500-$2K/month self-hosted

Approach 2: Continued Pre-training (Advanced)

When to Use

If you have large domain corpus (millions of security documents, 100M+ tokens) and want model to deeply "learn" security.

Process

  1. Gather Corpus: Security blogs, whitepapers, threat reports
  2. Pre-train: Continue training base model on security corpus
  3. Fine-tune: Then fine-tune on Q&A pairs
  4. RLHF (optional): Use human feedback to align responses

Cost: $50K-200K (much more expensive, only for very large deployments)

  • Add: Feedback on LLM responses quality
  • Active Learning: Retrain embeddings weekly on high-value queries
  • Drift Detection: Monitor if RAG accuracy degrades over time (concept drift)
  • Online Learning: Update model weights incrementally without full retrain
  • Benefit: Model improves continuously, adapts to new attack types

8. Explainability & Trust

  • Chain-of-Thought: LLM shows reasoning steps (already in reasoning pane!)
  • Source Attribution: Highlight exact sentence in retrieved docs that supports answer
  • Confidence Scores: LLM self-evaluates certainty (1-10 scale)

  • Translation Layer: Auto-translate docs → English for retrieval, translate response back

10. Federated Learning (Very Experimental)

  • Problem: Can't share sensitive incident data across companies
  • Solution: Train models locally at each company, aggregate model updates (not data)
  • Benefit: Collective improvement without sharing raw data
  • Use Case: Industry-wide threat intelligence without data sharing
  • Challenge: Complex infrastructure, poisoning attacks
